# Space Invaders CPP

## Español

Este es mi primer proyecto de game programming guiado gracias a la serie de artículos de [Nick Tasios](https://nicktasios.nl/posts/space-invaders-from-scratch-part-1.html), ¡super buena! La recomiendo a cualquiera que quiera dar un salto para ver cómo funcionan las cosas en el lado de game dev.

Está hecho en macOS y en el Makefile la referencia de las librerías es usando Homebrew. Cualquiera que desee tomar este código puede hacerlo tomando eso en cuenta.

Es un *Work In Progress*.
